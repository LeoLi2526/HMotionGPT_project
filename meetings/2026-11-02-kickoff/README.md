# 第一次研讨会：公开版任务摘要

**日期**：2026-11-02。原始会议纪要标为内部资料，保留在私有存档；本页只保留项目开展所需的技术方向与待核实事项。这里的设备输出、复现进展、人数和排期均不是已完成的实验结果。

## 方向

1. 用戒指、前臂 8 通道肌电臂环和第一视角相机采集日常手物操作，验证是否能以可接受的成本改善机器人 VLA 学习；优先复用现有硬件。
2. 三设备分别保存原始流、设备时间戳和配置，之后估计时钟映射并评估同步误差。先保证可导出、可同步、可重放，再比较连续融合与 token 化方法。
3. 一期先联调与小规模试采。采集规模、成本和质量门槛都要在试采后确定。

## 近期任务

| 顺序 | 任务 | 通过证据 |
|---|---|---|
| 1 | 核实戒指、臂环和相机实物版本、接口及时间字段 | 原始导出样例、配置和失败记录 |
| 2 | 确认机器人、两项可复位任务、动作字段与安全边界 | 机器人接口说明和动作来源 |
| 3 | 录制三流短任务并建立离线同步与 episode 重放 | 原始流、时间映射、留出事件残差和重放记录 |
| 4 | 在固定数据与预算下比较视觉、双模态、三模态和 token 化方法 | 完整实验记录；最终以机器人闭环结果判断价值 |
